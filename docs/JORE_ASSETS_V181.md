# JORE v1.8.1 asset integration

This patch integrates the provided JORE TUI Asset Pack into the full-screen terminal.

- adaptive 48/80/120-column logo assets
- mascot on roomy home screens
- loading animation text in the work dock
- JORE success/error language
- goodbye artwork after exit
- compact mode for shorter terminal windows
- footer and dock automatically reduce vertical usage

The public product name is **JORE** (pronounced **Yor-Eh / Yore**). The executable command remains `agenthub` for backward compatibility.
