# JORE v1.8.3 scroll/copy checks

- PageUp shows older conversation content.
- PageDown moves toward newer content.
- End restores newest-message follow mode.
- New events do not yank the viewport while the user is reading history.
- Mouse drag selects terminal text.
- Ctrl+Shift+C copies selected text.
- Ctrl+Shift+V pastes into the multiline composer.
- Arrow-key model/session pickers remain keyboard driven.
